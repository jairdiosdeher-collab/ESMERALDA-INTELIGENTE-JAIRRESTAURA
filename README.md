# Esmeralda Inteligente JairRestaura

Aplicación React + TypeScript + Vite para inventario, trazabilidad, procesos, valoración orientativa, movimientos comerciales y documentación educativa de esmeraldas.

## Requisitos
- Node.js 20 o superior
- npm

## Desarrollo local
```bash
npm install
npm run dev
```

## Compilación de producción
```bash
npm run build
npm run preview
```

## Despliegue en Vercel
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

## Almacenamiento y privacidad
Esta edición guarda datos en el almacenamiento local del navegador (`localStorage`). No sincroniza automáticamente entre dispositivos ni constituye una certificación gemológica o tasación oficial. Exporte respaldos JSON periódicamente y no almacene datos personales innecesarios.
